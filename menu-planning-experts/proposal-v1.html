一廠專家菜單自動規劃系統提案

依泳道圖縮小範圍：P0 資料就緒後，系統自動執行 P1＋P1b；人資下載、調整並回傳本週菜單。

目標

  1. #1P0 資料就緒後，系統自動執行 P1（硬性規則）與 P1b（軟性規則）。
  2. #2人資開啟系統，下載本週菜單檔。
  3. #3人資檢查後交給廚房；廚房回報變更（缺貨、超預算…）時，人資修改檔案並回傳系統。
  4. #4系統將調整後的檔案記為本週實際菜單，並據此依規則產生下週菜單。
  5. #5可查詢菜色清單；人資可新增或刪除菜色，兩者都持續依 P1/P1b 機制運作。

Automated Menu Planning System – Proposal for Plant 1

Scope narrowed per the swimlane: once P0 data is ready, the system runs P1 + P1b on its own; HR downloads, adjusts and returns the weekly menu.

Goals

  1. #1Once P0 data is in place, the system runs P1 (hard rules) and P1b (soft rules) by itself.
  2. #2HR opens the system and downloads this week's menu file.
  3. #3HR checks it and hands it to the kitchen; when the kitchen reports changes (shortages, over-budget…), HR edits the file and uploads it back.
  4. #4The system records the adjusted file as the week's actual menu and uses it to generate next week within the rules.
  5. #5Look up the dish list; HR can add or remove dishes, and both keep working under P1/P1b.
